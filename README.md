## What I'm building

我主要做能解决真实问题的小项目：桌面工具、网站与后台、AI 应用、自动化脚本和物联网应用。

这 100 个项目不是为了堆数字，而是一次次把想法做成体验的练习：小一点、实一点、说清楚、跑起来，再持续变好。
